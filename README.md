# אתר מכון בדיקות שמיעה — יבנה

אתר סטטי (HTML נבנה מראש) בעברית, RTL, מותאם למובייל, שמטרתו העיקרית היא הזמנת בדיקת שמיעה בוואטסאפ או בטלפון.

## מבנה הפרויקט

```
config/clinic.js          ← כל הפרטים האמיתיים של המכון. זה הקובץ היחיד שצריך לערוך.
src/templates/            ← תבניות הדפים (קוד, לא לערוך בשביל עדכון תוכן שוטף)
src/styles/main.css       ← עיצוב האתר
src/scripts/main.js       ← מעקב המרות (וואטסאפ/טלפון/טופס/ניווט) + תפריט מובייל
assets/                   ← לוגו, פאביקון, תמונת שיתוף (OG) — קבצים גולמיים
build.js                  ← הסקריפט שבונה את האתר הסופי
dist/                     ← *הפלט* — זה מה שמעלים לאחסון (נוצר מחדש בכל build)
CHECKLIST.md              ← רשימת כל הפרטים החסרים שצריך להשלים לפני עלייה לאוויר
```

## איך לעדכן פרטי מכון (השימוש היומיומי)

1. פתחו את `config/clinic.js`.
2. מלאו כל שדה שעדיין רשום בסוגריים מרובעים, למשל `"[PHONE]"`, בערך האמיתי.
3. הריצו:
   ```
   node build.js
   ```
4. תיקיית `dist/` תתעדכן עם כל הדפים. העלו את תוכן `dist/` לאחסון האתר (שרת/CDN).

**אין צורך לגעת בקוד התבניות** כדי לעדכן טלפון, כתובת, שעות פעילות, מחירים, פרטי צוות וכו' — הכול דרך `config/clinic.js`.

### הפעלת עמוד רופא אא"ג

עמוד `/ent-yavne/` אינו נבנה כלל כברירת מחדל. ברגע שיש בפועל רופא/ת אא"ג הפועל/ת במכון:

1. ב-`config/clinic.js` שנו `entEnabled: true` ומלאו את `entDoctor`.
2. הריצו `node build.js` — העמוד ייבנה ויתווסף אוטומטית לניווט, לכרטיסי השירותים במסך הבית ולמפת האתר.

### הצגת מחירים

כל עוד `pricing.confirmed` הוא `false`, האתר מציג "המחיר מתעדכן" בכל מקום שיש בו מחיר, ולא מספר מומצא. ברגע שיש מחירים סופיים — מלאו את השדות ושנו ל-`true`.

### שעות פתיחה מובנות (JSON-LD)

`openingHoursDisplay` הוא הטקסט שמוצג לגולשים. `openingHoursStructured` הוא מערך מובנה (ריק כברירת מחדל) שמזין את הנתונים המובנים (JSON-LD) לגוגל — דוגמה למילוי נמצאת כהערה בתוך `config/clinic.js`.

## דרישות טכניות

- **Node.js** (גרסה 18 ומעלה מומלץ) להרצת `node build.js`. אין תלות בחבילות חיצוניות (npm install לא נדרש).
- הבנייה היא **סטטית לגמרי** — כל עמוד הוא קובץ `index.html` עצמאי בתיקייה משלו (URL נקי, למשל `/hearing-test-yavne/`), כך שכל התוכן קיים ב-HTML גם ללא JavaScript.

## מה עוד חסר לפני עלייה לאוויר

ראו את `CHECKLIST.md` לרשימה המלאה. בקצרה:

- **תמונת שיתוף (OG)**: `assets/og-image.jpg` היא כרגע placeholder גרפי בלבד (1200×630). יש להחליף בתמונה אמיתית של המכון.
- **לוגו/פאביקון**: `assets/logo.svg` ו-`assets/favicon.svg` הם סימן זמני (איור גל קול). ניתן להחליף בלוגו סופי כשיהיה.
- **טופס יצירת קשר** (`/contact/`): כרגע שולח את הפרטים דרך `mailto:` בלבד (פותח את תוכנת המייל של המשתמש/ת). לפני עלייה לאוויר מומלץ לחבר נקודת קצה אמיתית (שירות טפסים, CRM, או שרת קטן) כדי לא להסתמך על כך שלכל מבקר/ת יש תוכנת מייל מוגדרת במכשיר.
- **דומיין אמיתי**: `siteUrl` בקובץ הקונפיג הוא placeholder. יש לעדכן לדומיין הסופי — הוא משמש לבניית ה-canonical URLs, sitemap.xml וה-JSON-LD.
- **Google Analytics 4 / Google Ads**: יש למלא את המזהים תחת `analytics` בקובץ הקונפיג. עד אז, אירועי המעקב (וואטסאפ, טלפון, טופס, ניווט) נצברים ל-`dataLayer` אך לא נשלחים לשום מקום.
- **Google Search Console**: לאחר פרסום הדומיין הסופי, יש לאמת בעלות ולשלוח את `sitemap.xml`.

## מעקב המרות (Google Analytics 4 / Google Ads)

`src/scripts/main.js` מאזין לכל אלמנט עם `data-track="..."` ושולח (כש-GA4 מוגדר):

| data-track | מתי נורה |
|---|---|
| `whatsapp_click` | לחיצה על כל כפתור וואטסאפ באתר |
| `phone_click` | לחיצה על כל כפתור/קישור טלפון |
| `directions_click` | לחיצה על קישור ניווט בגוגל מפות |
| `booking_form_submit` | שליחת טופס יצירת קשר |

כל אלמנט כזה נושא גם `data-track-location` (למשל `header`, `hero`, `sticky_bar`, `contact_page`) כדי לדעת מאיפה הגיעה ההמרה. Google Ads conversion labels מוגדרים תחת `analytics.conversionLabels` בקובץ הקונפיג.

## SEO טכני שכבר קיים בבנייה

- כותרת ותיאור meta ייחודיים לכל עמוד
- `<link rel="canonical">` לכל עמוד
- Open Graph metadata
- JSON-LD מסוג `MedicalClinic`/`LocalBusiness` בעמוד הבית (רק עם שדות מאומתים) + `BreadcrumbList` בכל עמוד פנימי
- `sitemap.xml` ו-`robots.txt` (מאפשרים במפורש Googlebot ו-OAI-SearchBot)
- HTML סמנטי, breadcrumbs, alt text לתמונות, ניווט מקלדת ו-`:focus-visible`
